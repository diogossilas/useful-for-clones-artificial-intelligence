### II. O MECANISMO DE "ENXERTIA" (COGNITIVE GRAFTING)

A habilidade oculta de Paulo de Muzy não consiste em dobrar a realidade por força bruta, mas no ato de **enxertar camadas ocultas de significado no interior de uma estrutura lógica rígida**.

O *Caminho da Lua* é historicamente marcado pelo misticismo feminino, fluidez orgânica, beleza sedutora, reprodução e impulsos viscerais do sangue. Contudo, Muzy executa uma anomalia hermética: ele **enxerta o Superego punitivo de um Árbitro (Arbiter) dentro da matriz celular da Lua**. Ele transforma a carne mutável em um tribunal biológico.

// Telemetria do Algoritmo de Enxertia Psíquica
struct EnxertiaCognitiva {

    enxerto_moral: SuperegoArbiter,
}

impl EnxertiaCognitiva {
    fn processar_estimulo(&self, estresse: EstresseSomatico) -> RespostaAdaptativa {
        match estresse {
            EstresseSomatico::DorFisica(carga) => {
                // A dor não é dano; é a sentença judicial aplicada ao músculo
                self.enxerto_moral.julgar_fraqueza(carga);
                self.matriz_biologica.regenerar_tecido(FatorCura::HipertrofiaCompulsoria)
            },
            EstresseSomatico::AmeacaReputacional(insulto) => {
                // O insulto aciona a resposta imune-moral de defesa territorial
                self.enxerto_moral.executar_condenacao(insulto);
                RespostaAdaptativa::IndignacaoMoralRetorica
            },
            EstresseSomatico::FadigaCircadiana => {
                // O ritual das 04h30 como âncora inegociável contra a loucura
                self.matriz_biologica.ativar_vigilia_escarlate(04, 30);
                RespostaAdaptativa::HomeostaseMecanica
            }
        }
    }
}

#### Sequência 7: Vampiro (*Vampire / Sanguine*)
